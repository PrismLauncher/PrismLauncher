# Facet Program Info

This is Facet's program info which contains information about:

- Application name and logo (and branding in general)
- Various URLs and API endpoints
- Desktop file

Icons are generated from `io.github.cakeru.FacetLauncher.svg` (app mark) and `io.github.cakeru.FacetLauncher.bigsur.svg` (macOS tile) with `genicons.sh`.
